Notes in a rich text editor, saved as Markdown files in a folder on your own disk. No account and no cloud.

Features

Your notes stay yours: plain files, on your own disk.

Rich editor, plain Markdown files

Formatting shows as you type: headings, bold and italic, lists and task lists, tables, code blocks, quotes, links and images. Every note is saved as a standard Markdown file.

Local and private

One folder on your disk holds the vault. Nothing leaves your computer.

Fast search

Matches the start of words, ignoring case and accents, with "exact phrases" and filters by notebook, tag, date and Trash. Title matches come first.

Notebooks

Organize notes into notebooks, renamed or deleted from the sidebar.

Nothing gets lost

Deleted notes go to the Trash for 30 days, every note keeps a revision history, the vault is backed up before anything is deleted for good, and a save that fails keeps your changes for recovery.

Attachments and images

Attach any file or insert images. Ctrl+click opens a link in its own app or the browser.

Import, export and print

Import Markdown and text files, also with "Open with". Export a note as Markdown, PDF or a self-contained HTML page, or print it.

Concurrency

Several windows, and computers on a local network, can work in the same vault at once. A note being edited elsewhere opens read-only and says where.

Your look

Light, dark or system theme, and your choice of editor font, size and highlight colours.
